# Linear Regression

Linear Regression is a supervised learning algorithm used to model the relationship between one or more input features and a continuous target variable.

## Topics Covered

- Problem Statement
- Mathematical Formulation
- Cost Function
- Gradient Descent
- Model Training
- Prediction
- Performance Evaluation
