# Mathematics for Machine Learning

Machine learning is built on a small number of mathematical disciplines. This section provides concise notes on the concepts required to understand and implement machine learning algorithms from scratch.

## Contents

| Topic | Description |
|--------|-------------|
| Linear Algebra | Vectors, matrices, matrix multiplication, eigenvalues, eigenvectors |
| Calculus | Derivatives, gradients, chain rule, partial derivatives |
| Probability | Random variables, probability distributions, Bayes' theorem |
| Statistics | Mean, variance, covariance, correlation, hypothesis testing |
| Optimization | Gradient descent, convexity, optimization algorithms |

---

## Goal

These notes are implementation-oriented.

Rather than proving every theorem, the focus is on understanding the mathematics needed to build machine learning algorithms from first principles.
